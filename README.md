## 常见问题

### ScraperAPI 免费试用需要绑定信用卡吗？

### 抓取 Google 搜索结果会被封号吗？

你用 ScraperAPI 的话不会。它在后端帮你做了代理轮换和指纹伪装，Google 看到的是分散的正常用户请求。封的是它的代理 IP，不是你的账号或服务器 IP。

### 返回的数据是 HTML 还是结构化的？

两种都支持。普通端点返回原始 HTML，你自己解析。Google Search 专用端点直接返回 JSON，字段都帮你提取好了。我建议直接用结构化端点，省事。

### 支持抓取哪些国家的 Google 结果？

支持全球主要国家和地区，通过 country 参数指定。美国、英国、日本、德国、法国这些都没问题。我测过日本和美国的结果，返回的确实是对应地区的本地化排名。

### 请求失败了会扣额度吗？

不会。只有成功返回 200 状态码的请求才计入用量。超时或者返回错误码的不扣。这点比较厚道。

### 年付和月付差多少？

年付大概能省三到四成。比如 Startup 套餐月付 $149，年付折算下来每月便宜不少。如果确定要长期用，年付划算很多。

### 能抓 Google 以外的网站吗？

能。ScraperAPI 本质是个通用抓取代理，任何网站都能抓。Amazon、eBay、社交媒体这些都支持。Google 搜索只是它的一个专项能力。
